🎄 Caixinha de Natal Virtual

Sistema web desenvolvido em Python e Django para facilitar a arrecadação de contribuições de Natal por meio do Pix.

🎯 Objetivo

Disponibilizar uma página acessível por QR Code, onde visitantes poderão selecionar uma pessoa cadastrada e realizar contribuições diretamente para sua chave Pix.

⚙️ Funcionalidades planejadas

- Acesso ao sistema por QR Code.
- Listagem pública de pessoas cadastradas.
- Cadastro, edição e gerenciamento de pessoas.
- Ativação e desativação de cadastros.
- Chave Pix individual para cada pessoa.
- QR Code Pix individual.
- Código Pix Copia e Cola.
- Painel administrativo protegido por login.
- Interface responsiva para celulares e computadores.

🛠️ Tecnologias

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

🚀 Hospedagem

O objetivo é publicar o sistema gratuitamente, utilizando o próprio computador Windows como servidor e avaliando uma solução de túnel HTTPS.
